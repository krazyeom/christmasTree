# GPU 눈송이와 손인식 동작 명세

기존 ASCII 트리 위에 WebGL2 눈송이를 겹쳐 표시한다. 카메라 손인식은 사용자가 버튼을 누른 뒤에만 시작한다. 원본 Instagram 영상은 직접 재생해 비교하지 못했으며, 공개 설명에 나온 손 추적과 GPU 눈송이 상호작용을 기준으로 구현했다. 원본과의 시각적 일치나 60fps 성능은 보장하지 않는다.

## 입력과 모바일 동작

- 카메라: 검지 끝을 따라 눈을 밀고, 엄지와 검지 사이의 거리가 임계값보다 작으면 소용돌이를 만든다. 좌표는 미리보기처럼 좌우 반전한다.
- 터치: 한 손가락으로 밀고 두 손가락을 모으면 두 접점의 중심에 소용돌이가 생긴다. 두 접점이 있는 동안 소용돌이가 유지된다.
- 마우스: 이동으로 밀고 왼쪽 버튼을 누른 상태로 움직이면 소용돌이가 생긴다.
- 트리 영역에만 `touch-action: none`을 적용한다. 페이지를 스크롤할 때는 트리 바깥에서 시작한다. 포인터 캡처로 영역 밖에서 손을 떼거나 브라우저가 입력을 취소할 때도 상태를 정리한다.
- 카메라가 켜져 있어도 손을 찾지 못하면 터치·마우스 입력을 사용한다.

카메라는 HTTPS 또는 해당 기기의 localhost처럼 브라우저가 인정하는 보안 출처에서만 동작한다. 휴대전화에서 PC의 일반 HTTP 주소로 접속하면 터치는 동작하지만 카메라는 사용할 수 없다. PC의 `localhost` 주소는 휴대전화의 PC 접속 주소가 아니다.

## 렌더러

[SnowWebGL2](file:///home/krazyeom/dev/christmasTree/app/snow-webgl2.tsx)는 Transform Feedback과 두 벌의 위치·속도·메타데이터 버퍼를 번갈아 사용한다. 초기 화면 폭이 768px 이하이면 28,000개, 그보다 크면 100,000개를 생성한다. `prefers-reduced-motion` 설정에서는 12,000개를 생성하며, 움직임을 완전히 멈추려면 일시정지 버튼을 사용한다. 회전이나 창 크기 변경은 캔버스 크기를 갱신하지만 파티클 수를 재선택하지 않는다.

파티클 렌더링 시 가산 혼합(Additive)으로 인한 화면 백화(White-out) 현상을 방지하기 위해 프리멀티플라이드 알파 블렌딩(`gl.blendFunc(gl.ONE, gl.ONE_MINUS_SRC_ALPHA)`)을 적용하고, 점 크기를 1.0~5.0px로 섬세하게 조정했다. 캔버스 `mix-blend-mode: screen`을 배제하여 28k~100k개의 눈송이가 흩날려도 중심의 ASCII 트리가 가려지지 않고 선명하게 빛나도록 보장한다. 모바일 툴바는 2단 중앙 정렬 레이아웃을 적용해 테마 버튼과 조작 버튼이 겹치거나 잘리지 않는다.

테마·눈·일시정지 변경은 기존 GPU 버퍼를 유지한다. 일시정지는 시뮬레이션 기록을 멈추고 마지막 버퍼를 그린다. 눈을 끄면 투명하게 지운다. 현재 두 상태 모두 프레임 콜백 자체는 유지한다.

초기화 실패나 WebGL 컨텍스트 손실 때는 ASCII 눈으로 전환한다. 컨텍스트가 복구되면 GPU 자원을 다시 생성한다. 셰이더, 프로그램, 버퍼, VAO, Transform Feedback 객체는 초기화 도중 실패하거나 컴포넌트가 해제될 때 정리한다. 영벡터 정규화와 역순 `smoothstep` 인자를 제거했다.

## 카메라 수명과 개인정보

[HandTrackerService](file:///home/krazyeom/dev/christmasTree/lib/hand-tracker.ts)는 시작 시도마다 스트림·비디오·모델을 따로 관리한다. 취소된 시도가 늦게 완료되어도 새 시도의 자원을 정지하지 않는다. 종료 시 트랙을 중단하고 비디오를 분리하며 모델을 닫는다. 페이지가 숨겨지거나 종료되어도 카메라를 끄며, 돌아왔을 때는 사용자가 다시 켠다.

모델 GPU 초기화에 실패하면 CPU 초기화를 한 번 시도한다. 권한 거부, 카메라 부재, 보안 출처 문제를 안내하고 터치 조작을 유지한다. PiP는 비디오 준비 후 연결되며 최소화했다 펼쳐도 다시 붙는다.

카메라는 오디오를 요청하지 않는다. 영상은 브라우저 메모리에서 처리하고 업로드·저장하지 않는다. 모델과 WASM은 같은 출처의 정적 자산을 읽는다. 이 변경은 인증·결제·파일 업로드 API를 추가하지 않는다.

## 검증 계획과 결과

- `npm run typecheck`, `npm run build`: 통과.
- `npm test`: 자산 검사, HTTP 응답/MIME 검사, 실제 tracker 모듈의 비동기 취소 회귀 검사 3개 통과. Node 22.6 이상에서 타입 제거 기능으로 TypeScript 모듈을 실행한다.
- 취소 회귀 검사는 이전 `video.play()`가 늦게 끝나는 경우와 취소 후 카메라 권한이 승인되는 경우를 재현한다. 새 세션이 살아 있고 오래된 트랙만 정리되는지 확인한다.
- 보안 검증: 명시적 카메라 동의, 마이크 미요청, 취소 시 트랙 종료, 보안 출처 검사, 외부 영상 전송 경로 부재를 코드에서 확인했다. 새 패키지나 외부 스크립트는 추가하지 않았다.
- 실제 브라우저 결과는 [작업 노트](file:///home/krazyeom/dev/christmasTree/notes/2026-11-23-mobile-camera-lifecycle.md)에 기록한다. 실제 휴대전화 하드웨어와 손 영상 추론 성능은 별도 확인이 필요하다.
