# 크리스마스 테마 리디자인 및 실시간 방문자 카운터 명세서

## 1. 개요
'little christmas' 서비스의 전체 시각 테마를 성탄 축제 감성의 딥 포레스트 그린 및 홀리데이 루비/골드 톤으로 전면 리디자인하고, 실시간 접속자 및 누적 방문자 수를 추적·표시하는 경량 방문자 통계 시스템을 구축한 기술 명세서입니다.

---

## 2. 크리스마스 비주얼 테마 시스템

* **배경 색상 및 무드 그라데이션**:
  - 기본 배경(`--bg`): 성탄 밤하늘의 딥 에메랄드 포레스트 톤 (`#05140f`)
  - 오로라 방사형 그라데이션: 상단 중앙의 포레스트 그린 조명(`#163c2c`), 좌측의 은은한 벨벳 루비 레드(`#35121b`), 우측의 윈터 엠비언스(`#123625`)를 블렌딩하여 환상적인 크리스마스 야경 연출.
* **타이포그래피 및 텍스트 엑센트**:
  - 서브 카피 (`.eyebrow`): 샴페인 골드 및 루비 레드 그라데이션 (`linear-gradient(90deg, #ffd166, #ff6584, #ffd166)`)
  - 메인 헤드라인 (`h1`): 캔들라이트 화이트 (`#fff8f0`) 및 골드 글로우가 적용된 이탤릭 엑센트 (`#ffd97d`, text-shadow 20px)
  - 설명 문구 (`.intro p`): 윈터 에메랄드 실버 (`#a8c7b8`)
* **브랜드 시그니처 엑센트 (`Y`, `S`, `W`)**:
  - `sig-accent` 클래스를 통해 앰버 골드(`#E09F3E`) 색상을 일관되게 유지.

## 3. 방문자 통계 시스템 아키텍처

```
[클라이언트 브라우저]
        │
        ├── 마운트 시 POST /api/visitors (sessionId 세션 전송)
        │      └─► 누적 카운트(+1) 및 활성 세션 타임스탬프 기록
        │
        └── 20초 간격 GET /api/visitors 폴링 (하트비트)
               └─► 실시간 접속자 수(active) 및 누적 방문자 수(total) 동기화
        │
        ▼
[Next.js API Route (app/api/visitors/route.ts)]
        │
        ▼
[.runtime/visitors.json (영속 저장소)]
```

### 주요 API 규격
* **엔드포인트**: `/api/visitors` (GET / POST)
* **응답 포맷**:
  ```json
  {
    "total": 1043,
    "today": 88,
    "active": 2,
    "sessionId": "x7b2k9zq1a"
  }
  ```
* **활성 사용자 판정 기준**: 최근 120초(2분) 이내에 핑이 감지된 고유 세션 수 집계 (최소 1명 보장).

## 4. UI 렌더링 위치
1. **상단 헤더 우측 (`.visitor-badge`)**: 붉은색 펄스 라이브 닷과 함께 `LIVE {active}명 접속 중 / 누적 {total}명` 실시간 표기.
2. **원더랜드 스테이지 바 (`.stage-top`)**: `LIVE ASCII WONDERLAND · 🎄 {active}명 감상 중` 표기.
3. **하단 개발자 상태 바 (`.dev-status`)**: `{total}명이 함께한 크리스마스 · ♥ {active}명 온라인` 표기.
