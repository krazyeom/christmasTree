# 3D 트리 시그니처 문자(Y, S, W) 고유 색상 및 별빛 쉬머 애니메이션 명세서

## 1. 개요
3D ASCII 크리스마스 트리를 구성하는 문자 엘리먼트 중 브랜드 시그니처 문자인 **`Y`, `S`, `W`** (대소문자 `y`, `s`, `w` 포함)에 차별화된 앰버 골드 색상과 고주파 펄스 별빛 쉬머(Shimmer) 이펙트를 부여한 캔버스 렌더러 명세서입니다.

---

## 2. 시그니처 문자 배치 및 렌더링 아키텍처 ([app/tree.tsx](file:///home/krazyeom/dev/christmasTree/app/tree.tsx))

### A. 기하학적 배치 알고리즘
* 트리의 각 층(row)과 둘레(j)를 따라 수학적 매듭 지점(`(row * 13 + j * 7) % 19 === 0 || (j % 11 === 3 && row % 5 === 0)`)에 `['Y', 'S', 'W', 'y', 's', 'w']` 문자를 고르게 분산 배치했습니다.
* 6개 모든 트리 스타일(클래식, 리본, 8-bit, 별자리, 매트릭스, 회로) 및 나선형 오너먼트 펜던트(`(Y)`, `{S}`, `<W>`)에 시그니처 문자가 일관되게 포함됩니다.

### B. 고유 렌더링 및 광채 연출 파이프라인
* **색상 전이**:
  - 기본 색상: 브랜드 핵심 강조 색상인 **앰버 골드 (`#E09F3E`)**
  - 쉬머 피크(Peak): 반짝임이 극대화되는 순간 밝은 **샴페인 화이트골드 (`#fff3d1`)**로 전환
* **차별화된 반짝임 (Dynamic Shimmer)**:
  - 일반 트리 잎사귀(1.8Hz)와 확연히 대비되는 **4.5Hz 고주파 코사인 위상 애니메이션**(`sin(t * 4.5 + x * 0.05 + y * 0.07) ** 2`) 적용.
  - 후광 반경(Shadow Blur)을 일반 포인트(0~9px) 대비 최대 **28px**(`(14 + shimmer * 12) * scale`)까지 대폭 확장하여 밤하늘의 1등성처럼 눈부신 광채 효과 구현.
  - 가시성 강화를 위해 폰트 굵기를 `bold 10.5px monospace`로 강조 렌더링.
